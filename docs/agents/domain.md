# Domain Docs

This is a single-context repo.

Before exploring, skills should read:

- `CONTEXT.md` at the repo root, if it exists
- `docs/adr/`, if it exists, for decisions relevant to the area being changed

If these files do not exist, proceed silently. Domain docs are created lazily when a skill resolves real domain terms or architectural decisions.

Use the vocabulary in `CONTEXT.md` when naming domain concepts in issues, refactor proposals, hypotheses, and tests.

If a proposal contradicts an ADR, surface the conflict explicitly.
